# Blazor UG Examples

## Overview

This repository contains Syncfusion Blazor User Guide (UG) examples that correspond to the Syncfusion Blazor documentation. The repository is organized into component-specific folders, with each folder containing sample projects that demonstrate documented features and usage scenarios. These examples provide runnable source code that can be used to understand component configuration, implementation patterns, and documented functionality within the Syncfusion Blazor component library.

## Key Features

- Contains Syncfusion Blazor User Guide sample projects organized by component folders.
- Includes dedicated folders such as `Accordion`, `AccumulationChart`, `AiAssistview`, `AppBar`, `AutoComplete`, `Barcode`, `Breadcrumb`, `Button`, `ButtonGroup`, `Card`, `Carousel`, `Chart`, `ChatUI`, `CheckBox`, `CircularGauge`, `ColorPicker`, `ComboBox`, `ContextMenu`, `DashboardLayout`, `DataManager`, `DatePicker`, `DateRangePicker`, `DateTimePicker`, `Diagram`, `Dialog`, `DropDownList`, `DropDownMenu`, `Gantt`, `Grid`, `HeatMap`, `InPlaceEditor`, `InputMask`, `Kanban`, `LinearGauge`, `ListBox`, `PivotTable`, `PreDefinedDialog`, `Ribbon`, `SmartComponents`, `SpeechToText`, `Tab`, `Toolbar`, `TreeGrid`, and `chips`.
- Provides sample implementations aligned with Syncfusion Blazor documentation.
- Organizes examples into component-focused projects for easier exploration and maintenance.
- Includes examples for data visualization, navigation, data management, scheduling, input controls, diagrams, layout controls, AI-related components, and productivity-focused components represented by the repository folders.

## Prerequisites

- Visual Studio 2022
- Visual Studio 2022 or Visual Studio Code
- .NET SDK compatible with the project's target framework

## How to Run the Project

**Visual Studio 2022**

1. Clone or download this repository.
2. Navigate to the component folder containing the sample you want to run.
3. Open the corresponding solution file (`.sln`) available within that component folder.
4. Restore all NuGet packages.
5. Set the selected sample project as the startup project if required.
6. Build the solution.
7. Run the application using `Ctrl+F5`.

**Visual Studio Code**

1. Open the repository folder in Visual Studio Code.
2. Open the integrated terminal.
3. Navigate to the desired sample project directory.

```bash
dotnet restore
dotnet run
```

4. Open the application URL displayed in the terminal after the application starts.
